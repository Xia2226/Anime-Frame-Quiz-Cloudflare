How to Play

游戏说明

项目介绍

这是一个根据动画截图猜番名的小游戏。经典和自由模式使用本项目构建的 Fancaps 截图库与 Bangumi 基础资料；困难挑战使用在线随机题源和识图服务。

三种模式

  • 经典模式： 随机抽取 50 部有截图番剧，每题 10 秒，满分 500 分，完整答完后参与每日积分榜。
  • 自由模式： 可按首播时间、评分、排名、热度、截图数和 Bangumi 标签筛选题库，计时计分规则与经典模式相同，但不参与排行榜。
  • 困难挑战： 使用在线识图生成题目，不限时；连续完成至少 50 题后，可按正确率参与每日排行榜。

计分与操作

经典和自由模式答对后，根据剩余时间获得 10、8、6、4 或 2 分；答错、跳过或超时不得分。可点击答案，也可使用数字键 1–4 选择，空格键跳过。

游戏页左上角的返回按钮会立即停止当前题目加载、倒计时和游戏循环，并返回首页；未完整完成的对局不会记录成绩。

排行榜与隐私

经典模式按得分排名，困难挑战按正确率排名。首次完成有效挑战后可以选择填写用户名，不填写则只查看榜单。困难挑战所需的 DeepSeek API Key 仅保存在当前浏览器会话中，通过请求头交给 Worker 使用，不写入排行榜数据库。

加载说明

经典和自由模式会先预加载 5 道题的截图再开始倒计时，并在答题过程中持续缓存后续图片。网络较慢时，首次进入游戏可能需要稍候。
